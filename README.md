# Arabic Handwritten Character Recognition

**ARTI 403 – Image Processing | Group 2**

**Instructor:** Dr. Manal

## Overview

Recognition of handwritten Arabic characters in low-quality images using image preprocessing, HOG and zoning features, SVM, and CNN.

## Dataset

[Click Here to Access the AHCD Dataset](https://github.com/mloey/Arabic-Handwritten-Characters-Dataset)

## Methodology

- **Preprocessing:** Centering, resizing, median filtering, Otsu's thresholding, and thinning.
- **Feature Extraction:** HOG and zoning.
- **Classification:** SVM and CNN.
- **Evaluation:** HOG comparison, SVM tuning, ablation study, and robustness testing under noise, blur, and rotation.
